# Smart Deal API reference

Base URL: `http://localhost:5050/api` (set `PORT` in `backend/.env`, `VITE_API_URL` in the storefront `.env`).

All responses are JSON. Success responses include `success: true`; errors return
`{ success: false, message }` with an appropriate HTTP status (400 validation, 401 not signed in,
403 forbidden, 404 not found, 409 conflict, 423 locked, 429 rate limited).

List endpoints accept `page` and `limit` and return `{ total, page, pages }` next to the items.

## Authentication

Access tokens are short-lived JWTs sent as `Authorization: Bearer <token>`. A rotating refresh
token is stored in the httpOnly `sd_refresh` cookie (path `/api/auth`), so browser calls must use
`credentials: "include"`. The storefront client in `src/lib/api.ts` handles refresh automatically.

| Method       | Path                                               | Body / query                                                                 | Notes                                                                                                                                                   |

| POST         | `/auth/register`                                   | `name, email, phone, password, role: "Customer" \| "Vendor", vendorDetails?` | Password needs 8+ chars with upper, lower, digit, symbol. Admin accounts can only be created by a super admin. Returns `{ accessToken, user }`.         |

## Catalog (public)

| Method | Path                               | Notes                                                                                                                                                                                                                                                                                                                  |
| ------ | ---------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| GET    | `/products`                        | Query: `q, category (slug, includes every level below it), brand (comma list), minPrice, maxPrice, rating, discount, inStock=true, tag, vendor, featured=true, flash=true, sort (relevance \| newest \| popular \| price-asc \| price-desc \| rating \| discount), page, limit`. Returns `products: ProductListing[]`. |
| GET    | `/products/facets`                 | Same filters; returns `{ facets: { brands[], priceRange, categories[] } }`.                                                                                                                                                                                                                                            |
| GET    | `/products/brands`                 | Active brands with counts.                                                                                                                                                                                                                                                                                             |
| GET    | `/products/lookup?ids=a,b`         | Listings for specific ids (guest wishlist, recently viewed).                                                                                                                                                                                                                                                           |
| GET    | `/products/categories`             | Active categories (flat, with `parentCategory` and `productCount`).                                                                                                                                                                                                                                                    |
| GET    | `/products/:slug`                  | `{ product, ratingBreakdown }`. Inactive products only for their seller or admins.                                                                                                                                                                                                                                     |
| GET    | `/products/:slug/related`          |                                                                                                                                                                                                                                                                                                                        |
| GET    | `/products/:id/reviews`            | Query: `sort (newest \| highest \| lowest), rating, page`.                                                                                                                                                                                                                                                             |
| GET    | `/products/:id/review-eligibility` | Auth. `{ canReview, reason }`.                                                                                                                                                                                                                                                                                         |
| POST   | `/products/:id/reviews`            | Customer who received the product. `rating, title?, comment` → queued for moderation.                                                                                                                                                                                                                                  |

`ProductListing` fields: `_id, slug, title, brand, category {name, slug}, vendor {name}, thumbnail, hoverImage, price, mrp, discountPercent, totalStock, inStock, rating {average, count}, soldCount, tags, isFeatured, isFlashDeal, flashDealEndsAt, defaultSku, variantCount`.

## Orders (customer)

| Method | Path                                             | Notes                                                                                                                                                                                                                |
| ------ | ------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| POST   | `/orders/quote`                                  | `addressId? \| emirate?, shippingMethod (Standard \| Express \| SameDay), paymentMethod (COD \| Card \| Wallet), couponCode?` → exact totals, shipping options, available payment methods.                           |
| POST   | `/orders`                                        | `addressId \| shippingAddress, billingAddress?, shippingMethod, paymentMethod, couponCode?, deliveryInstructions?, card? { last4, brand }, expectedTotal?` (403 until the email is verified, 409 if prices changed). |
| GET    | `/orders/my?status=active\|delivered\|cancelled` |                                                                                                                                                                                                                      |
| GET    | `/orders/:id`                                    | Mongo id or order number. Includes `capabilities { canCancel, canReturn, returnWindowEndsAt, canReview, reviewedProductIds, returnableItemIds }`.                                                                    |
| POST   | `/orders/:id/cancel`                             | `reason, refundMethod?, bankAccount?` — before shipping. Prepaid orders refund to `wallet` (default), `card` or `bank` (`bankAccount: { iban, accountName }`).                                                       |
| POST   | `/orders/:id/return`                             | `reason, comments?, refundMethod?, bankAccount?` — within the return window after delivery; non-returnable items are excluded from the refund.                                                                       |

VAT (default 5%) is charged on items − discount + shipping + COD fee. Card payments run through a simulated
test gateway while `PAYMENT_MODE=test`; card numbers never reach the server.

## Admin (role Admin, permission in brackets; super admins have all)

Staff with view-only access to a section can call its GET endpoints; changes need full access.
When `requireAdminMfa` is on, admin calls from staff without two-step sign-in return 403 with
`code: "MFA_SETUP_REQUIRED"` until they set it up.
